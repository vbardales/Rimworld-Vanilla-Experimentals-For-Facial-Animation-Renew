# Vanilla Experimentals for Facial Animation Renew (unofficial)

UNOFFICIAL. This mod is published without the original author's explicit consent. If the original author contacts me to request its removal, I undertake to take it down promptly.

An adaptation of **Vanilla Experimentals for Facial Animation** by SunshineyDays
([Steam 3753978140](https://steamcommunity.com/sharedfiles/filedetails/?id=3753978140), 2.3.4) to
the latest RimWorld version.

Vanilla-style moving eyes plus half-lidded tiredness, pain tears, hot, cold, gloomy and cheerful
overlays, and smiles and frowns for most mouths. Every part is optional through the mod settings.
Requires Harmony, [NL] Facial Animation, [NL] Facial Animation - Experimentals and Vanilla Textures
Expanded - [NL] Facial Animation.

Do not run it alongside the original mod; `<incompatibleWith>` declares the clash.

## Layout

    Mod/                the published folder, what Steam receives
      About/About.xml   metadata and the Workshop description
      1.6/              patches, the settings assembly, Keyed strings

    CHANGELOG.md        release notes
